# Matriz de testes para futura implementação

## Como interpretar

Todos os valores/candidatos sintéticos abaixo são **dados de teste**, nunca resultados oficiais. Exemplos numéricos reproduzidos do plugin são identificados como tal e não correspondem a uma edição confirmada.

- **Especificado:** o comportamento está explícito no ZIP; ainda precisa de teste automatizado/funcional quando implementado.
- **Pendente:** falta uma fonte, edição, decisão de produto ou regra sem ambiguidade para definir a saída confiável.
